# CC-Eval 评测 Schema v0.1

每道评测题是一个 JSON 对象（jsonl 一行一题），规范见 `item.schema.json`，真实示例见 `examples.jsonl`。

## 一、任务类型（task_type）

| 代码 | 任务 | 数据来源 | 评分方式 |
|---|---|---|---|
| KNO | 等级知识（字/词/语法点的等级定位、内容描述） | GF0025 四表 | exact_match |
| ERR | 偏误识别与纠正 | HSK 语料偏误标注 | set_overlap（类型+改正重合度） |
| SCO | 作文评分与反馈 | HSK 语料人工分数 | numeric_proximity（分数）+ llm_rubric（反馈质量） |
| GEN | 分级生成控制（限级改写/写话/出题） | GF0025 词表+语法表约束 | deterministic_rule（用词等级可机器判定） |
| CUL | 文化语用推理 | 文化框架 32 板块 | llm_rubric（量表锚定框架教学目标） |
| PED | 教学专业能力（教案评审、教材评价） | 教师/教材/职业三标准 | llm_rubric（rubric 即标准条目） |

## 二、核心设计决策

1. **anchor 必挂标准**：每题至少锚定一个标准条目（等级/语法点编号/词号/文化板块），保证"基于标准"可追溯，也使按维度切片统计成为可能。
2. **scoring 五选一并写明参数**：能确定性判分（KNO/GEN）的绝不用评委模型，保证可复现；开放题（CUL/PED/SCO 反馈）才用 llm_rubric，rubric 直接来自标准条目。
3. **contamination_risk 三级标注**：公开标准内容（KNO 类）模型大概率见过 → high，仅作基础门槛；HSK 语料正文受账号墙保护 → mid；全新生成的情境 → low。报告模型得分时按风险分层展示。
4. **provenance 记来源与授权**：HSK 语料题标记"学术研究使用，已向北语申请授权"。
5. **item_id 编码**：`CCE-<任务>-<等级>-<序号>`，等级 9 表示不锚定单一等级。

## 三、评分器实现状态

| 评分器 | 依赖 | 状态 |
|---|---|---|
| exact_match | 无 | 可直接实现 |
| set_overlap | 偏误类型集合比对 | 可直接实现 |
| numeric_proximity | 分数容差 | 可直接实现 |
| deterministic_rule | `gf0025-2021/vocabulary.json`（用词等级）+ 分词器 | 可直接实现 |
| llm_rubric | 需指定评委模型与打分提示词 | 待实现（V0.1 阶段可人工代评） |

## 四、示例

`examples.jsonl` 含 4 道从真实数据生成的示例题：

1. **CCE-ERR-9-0001**（偏误纠正）：取自 HSK 语料真实作文句（含 {CC2} 标注），金标准为语料库标注；
2. **CCE-KNO-2-0001**（等级知识）：语法点「存现句1」等级定位，锚定 grammar#104；
3. **CCE-GEN-2-0001**（分级改写）：把书面语段改写进二级词汇，用词表可机器验证；
4. **CCE-CUL-9-0001**（文化语用）：茶文化交际情境，量表锚定文化框架板块。
