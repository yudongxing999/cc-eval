# HSK 动态作文语料库（2.0）抓取数据

抓取时间：2026-09-05 ｜ 来源：hsk.blcu.edu.cn（用户本人注册账号，官方 API 导出）
用途声明：仅用于 CC-Eval 评测基准研究，不二次分发原始语料；正式使用前建议取得语料库方授权（申请函草稿见本目录）。

## 文件

| 文件 | 内容 | 规模 |
|---|---|---|
| `hsk_corpus.jsonl` | **主数据集**：每行一篇作文，含元数据+带标注正文 | 11,328 篇（20.3MB） |
| `hsk_metadata_all.csv` | 官方一次性导出的全库元数据（作文编码/国籍/性别/考试时间/题目/各科分数/证书） | 11,337 行 |
| `hsk_essays_text.json` | 作文编码 → 带偏误标注的正文原文 | 11,328 篇（8.2MB） |

差异说明：元数据 11,337 篇中有 9 篇正文接口持续返回服务器内部错误（重试确认不可得，占 0.08%），故正文覆盖 11,328 篇。缺失清单：200307209523200006, 200307201523100048, 200307205525100128, 199705104525200117, 199910512512250008, 200307271523200102, 199909529529251014, 200307271523100042, 199809542542200005。

## jsonl 字段

`id`（作文编码）/ `nation` / `gender` / `exam_date` / `title` / `scores`{koushi, zuowen, tingli, yuedu, zonghe, zongfen} / `certificate`（A/B/C/无）/ `text_annotated`（正文，含偏误标注）。

## 偏误标注体系（正文中 `{}` 内代码）

- `CC` 错字（前 2000 篇中 8455 处，最频繁）
- `CJ` 错词/用词不当、`CJX/CJZ` 其细分
- `CD` 多词、`CQ` 缺词
- `CP` 错标点、`WWJ` 未完成句、`CY` 语序等

正文中 `××` 为考生姓名脱敏占位。

## 分布概况

- 30 个作文题目，最多「绿色食品与饥饿」1,512 篇；
- 国籍 TOP3：韩国 4,167 / 日本 3,209 / 新加坡 843；
- 证书：C 4,209 / 无 5,316 / B 1,567 / A 236；
- 正文长度 15–2,950 字，平均 693 字。

## 对 CC-Eval 的用法映射

- **作文自动评分**：`scores.zuowen` 为人工真值，可按分数段分层抽样出题；
- **偏误识别与纠正**：`text_annotated` 标注即答案，可自动生成"找出偏误并改正"题；
- **分级反馈生成**：结合 GF0025 等级词汇表，检验模型反馈是否控制用词等级。
