# CC-Eval 语料库资源清单（2026-09-05 核实）

判定原则：本项目没有批量获取条件、或与国际中文教育场景相关性不足的一律剔除，不留"僵尸备选"。

## 一、已入库 ✅

| 语料库 | 规模 | 获取方式 | 状态 |
|---|---|---|---|
| HSK 动态作文语料库 2.0（北语） | 11,337 篇作文，371 万字，30 题 | 注册账号 + 官方 API（本项目已全量抓取） | **已入库**：`corpus/hsk_corpus.jsonl`（11,328 篇带偏误标注+分数） |

## 二、采用（可直接下载，条件已满足）✅

| 语料库 | 规模/内容 | 获取条件 | 用途 | 污染风险 |
|---|---|---|---|---|
| **CGED 历届评测数据**（github.com/blcuicall/cged_datasets） | 2014–2021 各届 train/test，二语学习者句级偏误诊断（R/M/W/S 四类） | CC BY-NC-ND 4.0，GitHub 直接下载，需引用 NLPTEA 论文 | 偏误识别任务的**公开对照基准**（可与业界系统横向比较） | **高**：模型训练语料大概率已包含 → 只作对照锚点，不计入核心区分度 |
| **CCL2022-CLTC**（github.com/blcuicall/CCL2022-CLTC） | YACLC-Minimal/Fluency 多参考纠错集 + Lang8 训练集 | GitHub 直接下载 | 流利度提升型反馈任务参考答案 | **高**：同上 |
| **MuCGEC 开发集**（github.com/HillZhang1999/MuCGEC） | 7,063 句多参考纠错（采样自 NLPCC18/CGED/Lang8） | 开发集 GitHub 直接下载；测试集仅天池在线榜单 | 纠错任务多参考答案格式参照 | **高**：且与 CGED/HSK 来源重叠，注意去重 |

> 污染风险说明：这三个数据集模型很可能"背过答案"。它们的正确用法是**校准锚点**（验证我们的评分器与业界 F0.5 可比），核心区分度题应来自 HSK 语料库中**未进入 CGED 公开集的部分**和新生成内容。

## 四、剔除 ❌

| 语料库 | 剔除原因 |
|---|---|
| 北大 CCL / 北语 BCC | 母语者语料，非学习者数据；只能在线检索、无批量授权。仅作为**工具**抽查模型生成文的母语自然度，不进数据集 |
| TOCFL 学习者语料库（台湾师大） | 跨境书面申请、繁体、周期不可控；其偏误类型已由 CGED 繁体部分覆盖 |
| FCGEC | 来源是母语者（中小学生病句+新闻），不是二语学习者，与本项目场景不符 |
| lang8_hsk（TW-NLP 156 万句） | 自动抓取的未审校数据，无权威标注，不能作金标准；如需大规模弱监督训练数据再考虑 |
| 暨南大学等其他校内中介语库 | 未公开对外服务入口，无从申请 |

- 文化语用 → 文化框架 32 板块（已结构化）
