## 细分发现（有诊断价值的）

| 子题型 | 得分率 | 解读 |
|---|---|---|
| kno.grammar_level | 15.5% | 模型对语法点所属等级只有"相邻级"粒度的印象（错答多为 ±1 级），**精确等级边界知识缺失** |
| kno.vocab_level | 22.7% | 同上，词级定位粗粒度 |
| kno.char_level | 40.0% | 字级略好（高等字特征明显） |
| err.detect_and_correct | 36.1% | 能改对一部分，但偏误类型判断与语料库标注口径差距明显 |
| sco.essay_score | 55.8% | 最强项：过半作文评分落在人工分 ±10 以内 |
| gen.level_controlled_rewrite | **0.0%** | **最重要发现**：模型完全无法在"限 N 级词汇"硬约束下改写（违规词如「音乐/交流/方式/文化」均为真违规），词汇等级产出控制能力是共性短板 |
| gen.words_to_passage | 57.1% | 宽松一点的限级写话过半通过 |
| ped.teacher_std_locate | 11.1% | 未见过《教师标准》 taxonomy，靠猜 |
| ped.textbook_std_locate | 4.4% | 同上，教材指标归类几乎全错 |
| ped.vocational_scenario | 98.5% ⚠️ | 评委给分宽松，开放设计题区分度不足 |

## 初步结论（对"通用模型在国际中文教育的实用价值"的回答）

1. **可直接用的**：作文粗评分（±10 容差下 55.8%）、文化知识讲解、开放式教学设计；
2. **不能直接用的**：严格按等级标准控制产出（0%）、精确引用等级标准条目（KNO/PED 归属 <25%）；
3. **介于中间的**：偏误纠正（能改但说不准类型）、限级写话。

这正好验证了基准的区分度设计：KNO/PED/GEN-rewrite 是区分度主力，CUL/职业场景题需要收紧 rubric 或换异源评委。

## 运行配置与复现

- 运行器：`runner/run_eval.py --model <m> --workers 10`（断点续跑，结果存 `results/<m>/`）
- 评委：`runner/judge_rubric.py <被测模型> <评委模型>`
- 汇总：`runner/summarize.py <模型>`
- k3-agent 已跑 238/1555（网关较慢，暂停，可随时续跑）
