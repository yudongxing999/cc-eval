## 2. 关键发现

### 2.1 「限级生成」是全行业共同短板
`gen.level_controlled_rewrite`（把一段文字改写为指定 HSK 等级可懂）120 道题：

| 模型 | 通过率 |
|---|---|
| 混元 hy3 | 15.0% |
| k3-agent | 8.3% |
| grok-3-mini-fast | 5.8% |
| deepseek-v4-flash | 4.2% |
| 豆包 seed-1-6 | 2.5% |
| glm-4-flash | 1.7% |
| ernie-4.5-turbo / qwen-flash / step-3.7-flash | 0.8% |
| k2d6-agent / deepseek-chat | 0.0% |

即使是表现最好的混元 hy3，也只有 15% 的改写能严格控制在目标等级词表内。对分级阅读材料编写、教材改写等真实教学场景而言，**通用模型开箱即用价值很低**，必须外挂词表约束（检索/解码约束/后校验）才可用。

### 2.2 「等级知识」普遍薄弱且不稳定
`kno.*_level`（判断某音节/汉字/词/语法点属于三等九级中的哪一级）总分区间仅 12.0–35.2。
- 最好的是 deepseek-chat（35.2），但其语法点定级也只有 19.5%；
- 通义（12.2）、智谱（12.0）接近随机水平。
- 结论：模型内部并未可靠记忆 GF0025 等级表，涉及"该教不该教、先教后教"的决策不可直接采信。

### 2.3 「作文评分」中文原生模型整体可用，但两极分化
以 HSK 动态作文语料库人工分数为锚（±1 级内给分）：k3 78.6 / ernie 76.8 / deepseek-chat 75.8 / qwen、zhipu 74+ / dsv4f 70.8 属于可用区；而**豆包 44.4、hy3 48.6、k2d6 55.8、grok 58.6 明显偏弱**——旗舰档的豆包/混元在该任务上反而大幅落后，评分口径与教学人工标准对齐度不足。该场景建议选型时单测，不可凭品牌推断。

### 2.4 「文化国情语用」普遍高分（70.5–94.9）
文化常识与语用得体性判断是各模型传统强项；glm-4-flash 70.5 相对最低，k3 94.9 最高（有同族评委偏袒风险），hy3 92.0 紧随其后。

### 2.5 「标准条文定位」几乎全军覆没
`ped.textbook_std_locate`（判断教材文本违反了《国际中文教材评价标准》哪条哪款）：11 个模型中 5 个为 0%，最高的 qwen 也只有 8.9%。模型不了解专门标准的具体条款编号，**不能指望通用模型做合规性审查**；但同维度的场景化教学设计题（ped.vocational_scenario，LLM 评委评分）各模型均在 98–100%，说明"会用教学常识"与"懂标准条文"是两回事。

### 2.6 「偏误识别与纠正」中等偏弱（21.5–36.1）
基于真实学习者语料的偏误标注任务上，k2d6 36.1 / 豆包 34.0 / k3 33.3 居前，zhipu 21.5 垫底。纠错可辅助，偏误类型归因不可尽信。

### 2.7 平台福利模型观察
deepseek-v4-flash（经腾讯 TokenHub）总分 42.9 列第 3，GEN 生成维度 50.8 明显强于官方 deepseek-chat（36.6）——新一代模型在教学文本生成上进步显著；但其等级知识（22.5）仍远低于 deepseek-chat（35.2），说明"标准记忆"并未随版本升级自动改善。

## 3. 方法论说明（防污染与局限）

1. **数据污染分层**：KNO/ERR 题答案直接来自公开标准文本与公开语料库，模型训练语料可能见过——高分不可全信，低分更能说明问题（连见过的都答不对）。GEN/PED 题为本次新构造（种子 20260905 程序化生成 + 模板变换），污染风险低。
2. **评分可靠性**：exact/numeric/set_overlap/rule 四类自动评分器共 1,357 题；llm_rubric 198 题由 k3-agent 按量表打分，存在同族偏袒与评委漂移，正式版拟引入第二异源评委 + 人工抽检校准（锚点：CGED/CLTC/MuCGEC 公开评测集）。
3. **模型档位偏差**：本次一律使用各厂免费/轻量档或现成可用档，结论仅适用于"该档位"模型；不代表各厂最高水平。
4. **单次采样**：温度为各 API 默认值，未做多采样投票，分数有 ±2 分左右的采样噪声。
5. **接入路径差异**：hy3 与 deepseek-v4-flash 经腾讯 TokenHub 国际站（新加坡）中转，网络与网关行为与官方直连略有差异，但对题目内容评分无实质影响。

## 4. 结论

在国际中文教育场景下，当前通用大模型的实用价值呈明显分层：

- **可直接用**：作文辅助评分（选对模型——k3/ernie/deepseek-chat 可用，豆包/混元旗舰反而偏弱）、文化国情问答、场景化教学设计草案；
- **需工程加固后用**：偏误纠正（需人工复核归因）、等级相关判断（需外挂标准检索）；
- **暂不可用**：限级生成（词表硬约束，最好的模型也只有 15%）、标准条文合规定位（最高 8.9%）。
