## 一、问题意识的聚焦

### 1.1 真问题是什么

通用大语言模型正在涌入国际中文教育现场：教师用它写教案、改作文，编者用它做分级读物，学生用它练表达。但所有应用方都卡在同一个起点上——**"这个模型在国际中文教育场景里到底好不好用"，没有任何客观的评价标准可依**。选型靠口碑、采购靠品牌、效果靠感觉。

通用 benchmark（MMLU、C-Eval 等）测的是通识能力，无法外推到垂直教育场景：一个 MMLU 高分的模型，可能完全不知道"把"字句在 GF 0025-2021 里属于几级、改写的课文是否超出了学生词表、给学习者作文的分数是否贴近人工评分。**没有度量衡，应用就是盲用。**

### 1.2 为什么"标准如何建立"是第一步

评价标准不是评测的副产品，而是整个智能化进程的前置基础设施：

```
评价标准建立（第一步）
    → 应用选型有据（当下价值：教师/编者/机构知道选谁、怎么用）
    → 模型改进有靶（中期价值：厂商知道往哪里优化）
    → 标准经充分验证与持续优化后
        → 作为奖励信号/数据筛选器，后训练出专属教育大模型
        → 或作为训练目标体系，孕育原生教育大模型（长期价值）
```

只有标准本身经过足够多的验证（多模型、多轮次、人工校准、信效度检验）并持续迭代，它才有资格成为训练的"指挥棒"。**本文解决的就是第一步：这个评价标准应该如何建立、建成后是否有效。**

### 1.3 与既有研究的区隔

- 通用 LLM 评测研究：不面向教育场景的专业约束；
- CALL/数智化教学研究：多为个案应用报告，缺乏可复现的量化标尺；
- 语言测试研究：测的是"学习者"，本文测的是"教学工具"——把语言测试的效度框架迁移到 AI 工具评价上。

## 二、拟定选题（最终方案）

### 2.1 标题

**《国际中文教育场景下通用大语言模型评价标准的构建与实证检验》**

英文：Constructing and Validating an Evaluation Standard for General-Purpose LLMs in International Chinese Language Education: The CC-Eval Framework and Its First Empirical Round

备选副标题变体：——兼论从评价标准到教育大模型的演进路径

### 2.2 核心论点

1. 通用大模型在专属教育场景的应用，需要专属评价标准；通用 benchmark 分数不可外推；
2. 评价标准的建立应遵循四条原则——**权威标准锚定**（以国家标准为答案锚点与生成约束）、**真实语料生态效度**（以真实学习者中介语为素材）、**教学任务场景化**（从教学现场工作抽象任务）、**确定性可复现评分**（自动评分器为主、量表评委为辅）；
3. 首轮 11 模型实证表明该标准具备区分度与诊断力：它能测出通用 benchmark 测不出的东西（"语言能力强 ≠ 标准知识可靠"的背离、限级生成全行业失守、评分效度档位倒挂等），证明了标准的有效性；
4. 标准的持续验证与优化，是后训练专属教育大模型乃至原生教育大模型的必经前置阶段。

### 2.3 拟定提要（≤300 字，投稿时精修）

通用大语言模型在国际中文教育场景中的应用日益广泛，但其适用性缺乏客观评价标准。本文提出垂直教育场景大模型评价标准构建的四条原则——权威标准锚定、真实语料生态效度、教学任务场景化、确定性可复现评分，并据此构建了国际中文教育评测基准 CC-Eval：以《国际中文教育中文水平等级标准》等权威文件为骨架，以 HSK 动态作文语料库真实学习者语料为素材，形成六类任务 1555 道题目。首轮对 11 个主流大模型的实证检验显示：各模型等级定级准确率仅 12.0%–35.2%，限级改写通过率最高 15.0%，标准条文定位最高 8.9%，而文化国情与教学设计任务表现良好，呈现"语言能力强、标准知识弱"的显著背离。研究表明该评价标准具有良好的区分度与诊断力。持续验证优化的评价标准可作为奖励信号与数据筛选器，为后训练专属教育大模型与原生教育大模型奠定基础设施。

**关键词**：大语言模型；评价标准；评测基准；国际中文教育；教育人工智能

## 三、期刊适配要点（《世界汉语教学》投稿要求）

- **结构**：标题 → 作者/单位 → 中文提要（≤300 字）→ 关键词（≤5 个）→ 正文 → 参考文献 → 英文题目/提要（100–200 词）→ 作者简介；联系方式另页
- **正文**：宋体五号；"一、二、"一级标题居中黑体五号；"1.1""1.1.1"前空两格；例句（1）（2）全文连排；注释用脚注
- **文献**：行文"冯胜利（2001：53）"，括注"（冯胜利，2001）"；中文在前按拼音、外文在后按字母；网络资源注明引用日期
- **投稿**：在线系统或 sjhyjx@blcu.edu.cn；双向匿名评审，周期 1–3 个月；不收版面费
- **适配性**：本文落脚于等级标准的数字化应用与学科建设，符合该刊"理论+实证+教学应用"取向；注意压缩工程细节，强化学科问题

## 四、审稿风险预判与应对

| 预判质疑 | 应对 |
|---|---|
| "这是工程报告而非语言学研究" | 问题意识前置：度量衡缺失是学科数字化转型的真问题；数据服务于"标准内化度"等语言学命题 |
| "题目答案来自公开标准，模型可能背过" | 污染分层设计；低分的诊断逻辑（背过仍答不对）；新构造题对照 |
| "LLM 评委可靠性" | 主观题仅 198/1555，主体为确定性评分器；附量表与抽检一致性 |
| "单次采样噪声" | 大题量效应量远超噪声；v1.1 多采样作为后续工作声明 |
| "与训练原生教育大模型的关系是否夸大" | 明确为"路径展望"而非已实现成果，援引 RLHF/奖励模型文献支撑 |

## 五、投稿前需补做的工作

1. **统计加固**：等级知识等任务补 95% 置信区间与模型间显著性检验（数据现成）；
2. **文献综述**：等级标准数字化、语言测试效度、LLM 评测、RLHF 四块中外文献（用 scholar 插件检索）；
3. **典型案例**：从 results 原始输出挑 3–5 个定性案例（如等级误判、超纲改写实例）增强语言学质感；
4. **评委信度**：第二评委或人工抽检一致性数据；
5. **格式排版**：按期刊体例出 Word 稿。
