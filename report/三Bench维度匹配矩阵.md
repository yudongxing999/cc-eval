> 2026-09-07 · 依据《国际中文教育大模型测评榜单建设规划》（梁远远）36 个二级维度，

## 六、需补充数据源清单（按优先级）

1. **分级阅读语料**（L3）：授权获取官方分级读物或 HSK 阅读考试文本；自建路线=文化框架概要+语法 reference_examples 构造，需人工校验难度；
2. **听力/口语语料**（L5/L6）：学习者朗读音频（PHO v1.2 的 corpus/audio/ 路线）或中介语语音语料库授权；
3. **翻译对齐语料**（L7）：中外平行句对；可从 GF0025 reference_examples 多大纲对照例句构造，外语侧需人工确认；
4. **学习者画像/错误档案**（T11/L10）：需教学团队合作采集；
5. **课程/教材序列数据**（L11）：教材级次序列（哪册教哪些语法点）可从 GF0025 语法等级大纲 + 现有教材评价标准部分推导，需专家确认；
6. **专家量表共建**（R1/R2/R5/R6/R7/R8/R9/R10 共 8 维）：研究方法专家 + 国际中文教育专家共建量表与金标例卷。

## 七、与 runner/harness 两条评测路线的对应

- **runner 路线**（生成式，1735 + v1.2 新 200 题）：三 Bench 首轮跑量主路线；llm_rubric 题占新增题多数（评委信度需按 v1.1 计划引入双异源评委）；
- **harness 路线**（loglikelihood 判别式，现 530 题）：覆盖 T1 本体知识、L1/L2 字词语法知识；rb.authenticity 的判别式改造（候选=真/假文献二选一）可入此路线；
- **榜单呈现**：按规划文档要求出「综合榜 + Teacher/Learner/Research 三专项榜 + 二级维度剖面」，CC-Eval 的 by_task/by_sub 汇总（runner/summarize.py）已支持按维度切片，新增 bench 维度标记见 §8。

## 八、题库 bench 维度标记（新题 schema 字段）

v1.2 新题在 `meta.tags` 之外增加 `meta.bench` 字段（`TB`/`LB`/`RB` + 二级维度编号，如 `TB-T2`、`RB-R12`），便于榜单直接按维度聚合；存量 1,735 题的 bench 映射以本矩阵 §2–§4 为准（汇总脚本可按 item_id 范围+任务类型映射，不需要改动存量题面）。
