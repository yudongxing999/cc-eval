## 三个来源的合规说明

1. **教材序列**：引用数据来自《等级标准》（GF 0025-2021）语法大纲公开出版的条目对照记录
   （"某语法点在《博雅汉语》初级起步篇I 第 4 课"），属标准字段引用，与 KNO 题同源模式；
2. **政府工作报告**：官方公开政治文献，中国翻译研究院公开发布中英对照。题目引用段落
   为评分锚点（gold_meta.official_en），发布题库含中文段+官方译法指针，不构成侵权性转载；
3. **HSK 真题**：官方下载中心公开提供（自测用，下载页明示）。本批题目为**改编引用**：
   数字替换、选项重排、场景问题重构，原卷（PDF/RAR）不入库（corpus/hsk_listening_raw/ 已加入
   .gitignore），题目 provenance 标注 `hsk-official`。

## "文本代理"边界（诚实声明）

- **L6 听力**：本批测的是**听力理解的文本面**（听到的内容已转写，考理解不考听辨）。
  真正的听觉通道评测（音频输入→理解）仍需多模态管线（PHO v1.2 规划的 corpus/audio/ 路线），
  本批的意义是先把"理解"与"听辨"分离，给文本模型一个可比较的基线；
- **L7 翻译**：测中→英公文翻译（术语定译+段落回译）。政府报告是政治文献标准语料，
  但学习者翻译需求的多样性（文学/日常/商务）覆盖不了，需后续扩充平行语料；
- **L11 路径规划**：测"教材序列知识"（哪个语法点先教后教）。完整的学习路径规划
  （目标+时间+资源推荐）还需课程结构数据，本批是其中的知识基础面。

## 已知残留风险（draft）

1. lr.pathplan 的课次引用来自语法大纲附录，个别记录可能与教材实际修订版次有出入——复核时
   抽 10% 对照原书目录；
2. lr.translation 术语题的干扰项是"其他术语的官方译法"，全部似真——区分度好，但需确认
   无一词多译歧义（如 "carbon peaking" 与官方 "peaking carbon emissions"）；
3. lr.listening 仅覆盖 HSK1 级别（一份真题的提取模板），2-6 级需再抓取对应真题扩充
   （下载中心 H21001/H31001/H41001/H51001/H61001 均为同结构，生成器可平移）；
4. 政府报告术语有政治时效性，年度更新后金标需随官方对照版刷新。
