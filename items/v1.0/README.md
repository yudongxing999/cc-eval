## 质量处理记录

- ERR：只取单标注句子；剔除含方括号位置标记（[BC]/[B历]）、嵌套标注、空改正内容的句子；学习者原文经"CD 保留内容、CQ 删除、其余去标注"规则还原；
- SCO：作文档案头（编号/Title 行）已剥离；仅取正文 150-900 字的作文；
- KNO：字定位题排除了多音重复字；词性为空的词不显示空括号；
- PED 职业场景：描述条目已剥离页码噪声，A/B 类分开锚定。

## 已知残留风险（待专业团队复核）

1. ERR 个别题的标注语义可能与直觉相反（如 {CC} 的改正方向），draft 状态需人工抽核 10%；
2. GEN 的 deterministic_rule 用词检查依赖 FMM 分词 + 词表，专名/儿化可能误判；
3. CUL 题目为模板化生成，区分度待实测；
4. KNO 类 contamination_risk=high（标准内容公开），只作门槛分。
