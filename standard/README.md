# CC-Eval 标准层数据

四份权威标准的结构化数据，作为 CC-Eval 基准的"骨架"（约束集 / 元数据 / 确定性校验规则 / 任务种子来源）。

## 一、GF 0025-2021 等级标准（gf0025-2021/）

| 文件 | 条数 | 字段 | 对应标准章节 |
|---|---|---|---|
| `syllables.json` | 1110 | no, level, syllable, example_char | 4 音节表 |
| `characters.json` | 3149（去重 3000，多音字按读音分行） | no, level, char, pinyin | 5 汉字表 |
| `handwriting_chars.json` | 1200（初等300/中等400/高等500） | no, band, char, pinyin | 5 手写汉字表 |
| `vocabulary.json` | 11092 | no, level, word, pinyin, pos | 6 词汇表 |
| `grammar.json` | 572 | no, level, category, subcategory, item, content, reference_examples | 附录A 语法等级大纲 |

`level` 取值：`1`-`6` 或 `"7-9"`（高等不按级细分，与标准一致）。
`grammar.json` 的 `reference_examples` 字段附带了与其他大纲（HSK考试大纲、国际汉语教学课程通用大纲、博雅汉语等）对照的例句，571/572 条有例句，可直接用于出题。

## 数据来源与校验记录（2026-09-05）

1. **原始文档**：用户藏书扫描版 PDF（257 页，仅 1 页有文本层）；教育部官网发布版 PDF（260 页，同为扫描版）。
2. **结构化基线**：GitHub 仓库 `shawkynasr/HSK-official-Query-System`（社区转录，2021-2026 年持续修订错字；原始 CSV 存于 `github-csv/`）。
3. **交叉校验方法**：pymupdf 渲染扫描页（200-300 DPI）+ RapidOCR 识别，与 CSV 逐词比对：
   - 词汇表：3 页抽查 190 词，189 命中（唯一未命中为"第（第二）"版式变体）；抽中词的分级标注与所在页章节（一级/六级/高等）全部一致。
   - 汉字表：一级汉字页 190/190 命中且等级正确。
   - 语法大纲：A.1.1.1 方位名词条目 OCR 与 CSV 逐字一致；各级条数 48/81/81/76/71/67/148=572 与标准量化指标总表完全一致。
4. **已知版本差异**：仓库内 `HSK 3.0-Yufa 2025 final.csv`（572 条，与标准一致）为语法基准；`with Reference Books` 版将二级"用'就'表示强调"与"是……的表示强调"拆为两行（573 条），整理时已以 final 为准。
5. **全书级复核（2026-09-05，第二轮）**：以《等级标准（国家标准·应用解读本）》三册全书 OCR（157+302+93 页）的"音序总表+分级表"双表对四个表逐条复核，不一致条目再回原标准扫描 PDF 仲裁。结果：词汇 10130/11092 总表直接一致；汉字总表 98.2% 一致；音节按（代表字+等级）比对 97.2% 一致；语法 572 条内容核对通过。**共确认 8 处社区转录错误**（词汇「显」5→6；汉字 谋/悬/抢/馒/素 6→7-9；语法 #40「语气助词→动态助词」、#104 存现句1 多余子项），已记录于 `gf0025-2021/errata.json`（原 JSON 未直接改动，供下游选择是否应用）；另有少量条目列入人工抽核清单。完整方法与裁决证据见 `interpretation/VERIFICATION.md`。

## 用途边界

- 作为评测题的 `level` / `grammar_point_id` / `vocab_level` 元数据字段；
- 作为确定性 scorer 的校验规则（如"给二级学习者的反馈用词不得超出 1272 词表"）；
- **不打包进开源仓库**：按既定策略，repo 中只放字段引用，不放标准原文。

## 二、文化和国情教学参考框架（culture-framework/）

来源：《〈国际中文教育用中国文化和国情教学参考框架〉应用解读本》（祖晓梅主编，语合中心，2023），336 页扫描版经 RapidOCR 全书识别（OCR 原文存 `raw/culture_text/`，第 1-3 章理论部分另存 `theory_ch1-3_ocr.txt`）。

| 文件 | 内容 |
|---|---|
| `culture_sections.json` | **32 个二级文化项目**（社会生活 13 / 传统文化 8 / 当代中国 11），每个含：内容概要全文 + 按学段（小学/中学/大学及成人）的教学目标（共 216 条）、关键词、讨论题举例、教学活动举例 |
| `teaching_cases.json` | 6 个完整文化教学教案（珍稀动物/家庭/茶文化/孔子/脱贫/中国画） |

OCR 噪声提示：个别字有误识（如"消遭"="消遣"），讨论题偶有断行丢号；概要正文质量高，用于出题前建议抽校。

## 四、对 CC-Eval 的用法映射

- **文化语用推理题**：以 `culture_sections.json` 的 32 板块为话题轴，讨论题举例可直接改写为评测输入，教学目标可作 rubric 锚点；
- **教学适配性 rubric**：教师标准的 73 条能力描述 + 三级认定条目即"好教师行为"的权威清单，可原子化为评分判据；
- **教材/资源评价任务**：教材评价标准 85 条指标（尤其定性 59 条带权重）可直接转成"模型评审教材"任务的打分表；
- **职业中文场景题**：职业中文标准的"等级×A/B类×四技能"矩阵是现成的情景生成参数。
