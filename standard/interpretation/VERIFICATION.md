# 标准层数据复核报告（GF0025-2021 结构化 JSON）

复核日期：2026-09-05
复核对象：`standard/gf0025-2021/` 下五个 JSON（整理自社区 CSV）
复核依据：
- 《国际中文教育中文水平等级标准（国家标准·应用解读本）》三册（祖晓梅主编解读本体系配套）—— 第一分册（157 页）、第二分册（302 页）、第三分册（93 页）全书 120dpi OCR；
- 教育部/国家语委原标准扫描 PDF（257 页）关键页段 OCR 仲裁。

方法：解读本"音序总表/分级表"双表独立锚定解析 → 与 JSON 比对 → 不一致条目回原标准 PDF 对应页段二次仲裁。

## 关键裁决记录

- **「显」的级别**：解读本第二分册总表标六级；原标准 PDF 五级段（#851-1071）无「显」、六级段有「显出」（#879）。→ JSON 错。
- **谋/悬/抢/馒/素**：解读本第一分册分级汉字表七-九段与原标准汉字表七-九段（i025-031）双重确认属高等，六级段无。→ JSON 错（社区 CSV 把高等字误标六级）。
- **语法 #40 变化态**：原标准第 180 页 A.1.5【一40】原文「用动态助词"了2"表示」，解读本 p027 同。JSON 作「语气助词」。→ JSON 错。
- **语法 #104 存现句1**：原标准第 190 页【二56】与解读本 p036 均只含两项子句（处所+有…、处所+动词+着…），JSON 多出的「处所+是…」子项两书均无。→ JSON 混入。
- **语法 #206**：「用'是'表示强调」vs 标准「用'是'强调」，仅措辞详略，不改。
- 汉字「事/旗/押/赠/章」、音节 7 条、词汇 55 词：OCR 覆盖/单字识别限制，未裁决，列入人工抽核清单（见 errata.json `pending_manual_check`）。

## 残留风险

1. 音节表按（代表字，等级）比对，声调符号层面未逐条校验（OCR 对声调不可靠）。
2. 解读本与原标准本身若有出入，以原标准为准的仲裁只覆盖了不一致条目，未做全书逐条双源校验。
3. 单字 OCR 失败导致词汇表存在 55 词无法机器确认（概率上多为识别失败而非真缺失）。
